# Cosmos Launcher

Нативный Android-лаунчер на Kotlin.

## Что уже реализовано

- Три рабочих стола с плавно движущимися шарами приложений.
- Оригинальные иконки приложений внутри стеклянных сфер с подписями.
- Мягкие столкновения шаров и отскоки от границ экрана.
- Перетаскивание шаров без скачка под пальцем.
- Объединение приложений в папки; содержимое папки открывается отдельной сеткой.
- Неподвижный нижний Dock с пятью закреплёнными приложениями.
- Закреплённые приложения не дублируются на рабочих столах.
- Сохранение расположения, папок и последнего открытого рабочего стола.
- Возможность выбрать Cosmos Launcher как домашний экран Android.

## Сборка

APK собирается вручную через GitHub Actions:

1. Открыть вкладку **Actions**.
2. Выбрать **Build Cosmos Launcher APK**.
3. Нажать **Run workflow**.
4. После успешной сборки скачать артефакт **Cosmos-Launcher-debug**.

Сборка не запускается автоматически при каждом коммите.
