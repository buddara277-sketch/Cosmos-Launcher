# Cosmos Launcher

Первая версия Android-лаунчера на Kotlin.

- Получает установленные приложения и их настоящие иконки.
- Иконки плавно движутся, сталкиваются и отскакивают от границ экрана.
- Нажатие открывает приложение.
- Перетаскивание задаёт иконке импульс.
- Можно выбрать Cosmos Launcher как домашний экран Android.
- GitHub Actions собирает APK после отправки изменений в main.

Следующий этап: движущиеся папки, вложенные пространства и нижняя панель.
